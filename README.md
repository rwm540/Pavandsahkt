# پلتفرم آکان (AKAN) | اکوسیستم جامع معاملات امن و زنجیره ارزش ملک و ساختمان

پلتفرم **آکان** یک سامانه یکپارچه، امن و نوین در حوزه املاک، ساخت‌وساز، مصالح ساختمانی و معاملات چندوجهی است که با هدف حذف واسطه‌گری ناسالم، تضمین سلامت اسناد ثبتی، ایجاد اتاق‌های معامله محرمانه و اتصال مستقیم سازندگان به تأمین‌کنندگان مصالح طراحی شده است.

---

## 🌟 ویژگی‌ها و ماژول‌های اصلی پلتفرم

### ۱. سامانه اعتبارسنجی حقوقی و اسناد (Legal Document Verification)
- استعلام وضعیت ثبتی اسناد (تک‌برگ، شش‌دانگ، آزاد و بدون بازداشتی).
- اعطای نشان سلامت ثبتی به فایل‌های کارشناسی‌شده و حذف فایل‌های نامعتبر.
- تضمین قیمت کارشناسی و تاریخچه معاملات معتبر.

### ۲. اتاق معامله محرمانه و امن (Confidential Deal Room)
- ثبت پیشنهادات قیمت رسمی و محرمانه بدون افشای اطلاعات طرفین.
- پرداخت بیعانه از طریق حساب امانی امن (Escrow Service).
- قراردادهای تیپ حقوقی هوشمند و تاییدیه با امضای دیجیتال OTP.
- مراحل گام‌به‌گام شفاف: پیشنهاد قیمت، بررسی حقوقی، واریز بیعانه، امضای قرارداد و تحویل ملک.

### ۳. نمایشگر تعاملی سه‌بعدی ملک (Interactive 3D Property Viewer)
- نمایش لایه‌های معماری ملک در فضای سه‌بعدی با زاویه پرسپکتیو و کنترل زاویه دید.
- بررسی لایه‌های نما (Exterior)، پلان معماری (Interior Floorplan)، تاسیسات و تجهیزات (Facilities) و مدارک ثبتی (Documents).

### ۴. بازار مصالح ساختمانی و زنجیره تأمین (Building Materials Marketplace)
- اتصال مستقیم سازندگان به کارخانجات و تولیدکنندگان عمده (سیمان، فولاد، میلگرد، سرامیک، تاسیسات).
- مقایسه قیمت لحظه‌ای، تحویل در پای کارگاه و امکان پرداخت اعتباری (LC / برات).
- سیستم ثبت استعلام قیمت و دریافت سریع پیش‌فاکتور رسمی.

### ۵. میز هوشمند تهاتر تخصصی (Barter & Trade Exchange)
- امکان تهاتر ملک با ملک، تهاتر ملک با مصالح ساختمانی یا خودرو.
- ماشین حساب محاسبه سرک نقدی (Cash Balance Difference).
- اعتبارسنجی حقوقی ارزش‌گذاری طرفین تهاتر.

### ۶. سامانه مشارکت در ساخت (Construction Partnership)
- ثبت زمین‌های مستعد ساخت با تعیین آورده مالک و نسبت سهم پیشنهادی.
- ارزیابی رزومه و رتبه اعتباری سازندگان و پیمانکاران.
- پایش مراحل ساخت و فازهای اجرایی پروژه با گزارش‌های ادواری.

### ۷. دیتاسنتر و شاخص قیمت مسکن (Real Estate Price Index & Estimator)
- نمودارهای روند تغییرات قیمت هر متر مربع به تفکیک مناطق و شهرها.
- تخمین‌گر هوشمند قیمت ملک بر اساس متراژ، سال ساخت، طبقه و موقعیت جغرافیایی.
- دسترسی به آمار و داده‌های معاملات قطعی ثبت‌شده.

### ۸. ساختار کاربری چندنقشی (Multi-Role Ecosystem)
پلتفرم به تفکیک نیازهای هر یک از نقش‌های زیر محیط و داشبورد اختصاصی ارائه می‌دهد:
- **خریدار و سرمایه‌گذار**: جستجوی فایل‌های سالم، ثبت پیشنهاد در اتاق معامله.
- **مالک و فروشنده**: ثبت مستقیم فایل، پیگیری استعلام سند و دریافت پیشنهادات رسمی.
- **مشاور املاک امین**: مدیریت فایل‌ها، پنل کارگزاری و پورسانت مصوب.
- **سازنده و مجری**: خرید عمده مصالح، ثبت درخواست تهاتر و پروژه‌های مشارکت.
- **کارخانه و تولیدکننده مصالح**: ثبت تیراژ، قیمت‌گذاری و پاسخ به پیش‌فاکتورها.
- **فروشنده محلی و استادکار**: ارائه خدمات تخصصی، اجرا و پیمانکاری.
- **مدیریت ارشد (ادمین)**: ممیزی اسناد، نظارت بر اتاق‌های معامله و گزارش‌های تخلف.

## 🎨 طراحی بصری و تجربه کاربری (UI/UX)

- **طراحی شیشه‌ای لوکس (Glassmorphism & Depth)**: بهره‌گیری از پنل‌های شیشه‌ای بلورین با فیلتر بلور تیره، خطوط نوری و سایه‌های سه‌بعدی.
- **تایپوگرافی استاندارد فارسی (Vazirmatn)**: استفاده از فونت استاندارد و خوانای وزیری در تمامی بخش‌ها و ارقام فارسی.
- **کارت‌ها و دکمه‌های لمسی سه‌بعدی (3D Tactile Elements)**: بازخورد تعاملی لمسی با انیمیشن‌های روان فریم‌ورک `motion`.
- **طراحی واکنش‌گرا و سازگار با موبایل (PWA Ready)**: سازگاری کامل با نمایشگرهای موبایل، تبلت و دسکتاپ.

## 🛠 فناوری‌های مورد استفاده (Tech Stack)

- **Frontend Framework**: React 19 + TypeScript
- **Styling & Layout**: Tailwind CSS v4 (Glassmorphism, 3D Utilities, RTL)
- **Charts & Data Viz**: Recharts
- **Icons**: Lucide React
- **Animations**: Motion
- **Build Tool**: Vite

## 🚀 نحوه نصب و راه‌اندازی محلی (Getting Started)

### پیش‌نیازها
- Node.js (نسخه ۱۸ یا بالاتر)
- npm یا bun

### گام‌های اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه پروداکشن
npm run build
```

پس از اجرای دستور `npm run dev`، سامانه روی آدرس `http://localhost:3000` در دسترس خواهد بود.
